StimASD: A fine-grained dataset and balanced patch-partition embedding approach towards self-stimulated behavior recognition in autism

We construct a fine-grained dataset of self-stimulatory behaviors in autism, termed StimASD. This video dataset contains 8 categories and 520 clips, with fine annotation and diverse samples. 202 videos are obtained, which 27 originated from the SSBD dataset. To ensure fine-grained data quality, these videos are segmented to contain only a single behavior category. Each video clip is annotated in 'StimASD.xlsx', including the occurrence time, duration, body parts involved in the action, and the number of individuals.
0 - Arm flapping;
1 - Finger flicking;
2 - Head banging;
3 - Spinning;
4 - Toe walking;
5 - Beating oneself;
6 - Rocking back and forth;
7 - Hand biting;
